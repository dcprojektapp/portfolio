# Sprawdzarka

> Agent AI sprawdza prace uczniów z egzaminów zawodowych (INF.03) i tworzy interaktywny raport HTML.

**Technologie:** agenci AI (Claude Code / Codex) sterowani instrukcjami `AGENTS.md` · HTML/CSS/JS · skrypt .bat

## Jak to działa
1. W folderze klasy jest treść zadania (PDF) i prace uczniów.
2. Agent analizuje zadanie i dobiera kryteria oceniania (HTML, CSS, JS, PHP, SQL).
3. Sprawdza każdą pracę i przyznaje punkty z uzasadnieniem.
4. Tworzy raport HTML według wzorca: filtrowanie, wyszukiwanie, zwijane sekcje.

## Efekt
Godziny ręcznego sprawdzania zamieniają się w raport, który nauczyciel weryfikuje i omawia z uczniami. Obsługuje wiele klas.
