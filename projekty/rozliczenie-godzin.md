# Rozliczenie godzin

> Lekka aplikacja przeglądarkowa do ewidencji i rozliczania godzin pracy.

**Demo:** [https://dcprojektapp.pl/demo/godziny/](https://dcprojektapp.pl/demo/godziny/)  
**Technologie:** HTML · CSS · JavaScript

## Funkcje
- Zastępuje ręczne prowadzenie arkusza Excela
- Wprowadzanie godzin i automatyczne podsumowania
- Działa w przeglądarce, bez instalacji i bez serwera
