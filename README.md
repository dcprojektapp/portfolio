## 🧠 Jak pracuję z AI

1. **Discovery:** plik `IDEA.md` opisuje niszę, frazy wyszukiwania w sklepach, propozycję wartości i zakres MVP.
2. **Zasady dla agentów:** `CLAUDE.md` / `AGENTS.md` ustalają architekturę (np. Clean Architecture z warstwami UI → Cubit → Repository → Data Source), dozwolone biblioteki i styl kodu.
3. **Iteracje:** agent implementuje funkcję, a ja ją weryfikuję, testuję na urządzeniu i poprawiam kierunek.
4. **Stan projektu:** `STATE.md` lub `POSTEP.md` śledzi etap budowy, dzięki czemu każda sesja z agentem zaczyna się od aktualnego kontekstu.
5. **Publikacja:** metadane do sklepów, zrzuty ekranu, polityka prywatności i usuwanie konta.
